# iKontrol 1.1.0

Release date: 2026-10-01. Release reference: `release/1.1.0`.

This baseline makes the Smartfree prefiscal bridge self-contained, adds MariaDB 10.6-compatible payment-complement identity, completes the bridge schema required by runtime, formalizes SAT catalog installation, projects safe fiscal modes, and introduces resumable directed instance upgrades and centralized feature flags.

Existing Smartfree data, IDs, orphan rows, payments, allocations and monetary totals remain governed by the certified bridge reconciliation. No historical CFDI is invented. Production PAC remains blocked until the fiscal status reports `PRODUCTION`.

Known release blocker: the official ten SAT CSV artifacts and populated manifest stated for this release are absent from the current checkout. Do not run the final 1.0.0 → 1.1.0 production upgrade or a clean 1.1.0 installation until those checksummed artifacts are present and validated.
